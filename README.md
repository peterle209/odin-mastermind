# odin-mastermind

## About this project
CLI implementation of the board game "mastermind". For an explanation of mastermind, check [here](https://www.wikihow.com/Play-Mastermind).
## Usage
- This project assumes you have ruby installed, if you do not, check [here](https://www.ruby-lang.org/en/documentation/installation/) for an installation guide
- To start, input "ruby main.rb" to your terminal while in the project directory
- Choose whether you would like to create the code (code maker) for the computer to guess or try to guess the code (code breaker) generated by the computer
- If you choose to create the code, you may input as many colors as desired. The code does assume you are inputting colors, but you may choose a string such as "shark green red pickle" and things will still work as intended, as non-color words will be treated as possible guesses for the computer.
- If you choose to guess the code, you will be given the code length as well as the possible colors the code may be made up of. You may continue to guess until you run out of turns, in which case, it will be a loss.
